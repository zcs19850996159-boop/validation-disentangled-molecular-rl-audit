# REINVENT4 安装与基线运行指南

> 以下步骤基于 REINVENT4 主分支最新代码验证（`reinvent/scoring/scorer.py`、
> `reinvent/scoring/config.py`、`reinvent/runmodes/RL/learning.py`）。

## 1. 安装

```bash
git clone https://github.com/MolecularAI/REINVENT4.git
cd REINVENT4

# 用 conda（也可以用 uv，见官方 README）
conda create --name reinvent4 python=3.10
conda activate reinvent4

# 按你的硬件选处理器类型：cu126 / rocm6.4 / xpu / mac / cpu
python install.py cpu   # 没有GPU先用cpu跑通流程，调好方法后再上GPU
reinvent --help          # 能看到帮助信息说明装好了
```

## 2. 下载 prior 模型（必须单独下载，仓库里不含权重文件）

REINVENT4 从某个版本起把 prior 权重移到了 Zenodo，仓库 clone 下来是没有
`priors/` 目录的，必须手动下载，否则跑 RL 会直接报找不到文件：

```bash
mkdir -p priors
wget -O priors/reinvent.prior \
  "https://zenodo.org/records/15641297/files/reinvent.prior?download=1"
```

TOML 配置里可以用点号引用内置 prior（见 `reinvent/utils/prior_registry.py`），
比如 `prior_file = ".reinvent"`，这样就不用自己管路径；也可以像下面配置文件里
那样直接写相对路径 `priors/reinvent.prior`，两种都可以，我用的是后者，更直观。

## 3. 跑通一个基线（先不接controller，确认环境没问题）

用本目录下的 `02_baseline_multiobj.toml`：

```bash
reinvent -l baseline.log 02_baseline_multiobj.toml
```

这个配置做的事情：用默认的 REINVENT prior，跑一个两阶段 staged learning，
优化目标是 QED（类药性）+ 分子量落在合理区间，这两个都是纯计算指标，不需要
额外的模型或数据库，几分钟内能在CPU上跑完，可以用来验证环境和流程是通的。

跑完后 `tb_logs/` 目录下有 TensorBoard 日志，可以用
```bash
tensorboard --logdir tb_logs
```
看训练曲线（分数、prior/agent似然、loss等）。

## 4. 接入你的 controller

见 `03_dynamic_weight_controller.py`，里面有详细注释说明怎么把它接到上面
这套流程里，不需要改 REINVENT 任何核心代码。

## 5. 关键代码位置备忘（后续调试用得上）

| 内容 | 文件 | 说明 |
|---|---|---|
| RL主循环 | `reinvent/runmodes/RL/learning.py` `Learning.optimize()` | 每个 `step` 调用一次 `self.score()` |
| 打分聚合入口 | `reinvent/scoring/scorer.py` `Scorer.compute_results`（即 `Scorer.__call__`） | 把各组件分数按权重聚合成 `total_scores` |
| 权重存储位置 | `reinvent/scoring/config.py` `get_components()` | 每个组件的 `(names, scoring_function, transforms, weights)` 存在 `ComponentData.params` 里，`weights` 是一个list，可原地修改 |
| 权重来源 | TOML里每个 `endpoint.weight` 字段 | 默认值1.0，当前版本里训练全程不变——这正是你要改造的地方 |

下一步建议先手动跑通第3步的baseline，确认环境没问题，再看第4步的controller代码。
